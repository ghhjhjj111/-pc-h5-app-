获取源码：ym7k.com/11811/
知识付费系统采用 PC + 小程序 + H5 + APP 多端方案，前端常用 UniApp（一套代码编译多端），PC 端单独用 Vue + Element；后端多为 ThinkPHP 6/8 或 Laravel，提供统一 API。

核心模块：图文/音频/视频/专栏/直播课程、会员体系、订单支付、分销拼团、优惠券、讲师入驻、学习进度、考试题库、数据统计。管理后台支持 RBAC 权限、多角色协作。

多端要点：用条件编译处理各端支付、登录、分享差异——微信小程序用 wx.login + 微信支付，H5 用公众号授权 + JSAPI，APP 用原生支付，PC 用扫码支付。视频需对接 OSS + CDN 防盗链，直播接第三方推拉流。

常见坑：号称全开源但核心文件加密；多端只有微信真跑通，其他端支付登录是空的；视频域名未配置；分销层级超三级涉传；虚拟商品退款规则不清。

合规红线：ICP 备案 + 经营性 ICP 许可证、网络文化经营许可证（音视频/直播）、出版物经营许可证（电子书）、个人信息保护、版权授权、发票税务。
